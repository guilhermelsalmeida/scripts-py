# Curso de Python.

## Programas em Python

Repositório com exercícios e pequenos programas em **Python 3** que desenvolvi durante meus estudos. Acompanham o curso de Python 3 do [Curso em Vídeo](https://www.cursoemvideo.com) e mostram minha evolução na lógica de programação. O repositório é atualizado conforme avanço nas aulas.

### O que já pratiquei

- Entrada e saída de dados
- Operadores e cálculos
- Estruturas condicionais (if, elif e else)
- Laços de repetição
- Manipulação de texto
- Pequenos jogos e programas interativos

### Como executar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Clone o repositório:

       git clone https://github.com/guilhermelsalmeida/scripts-py.git

3. Abra a pasta do repositório no terminal.
4. Execute um programa:

       python nome_do_arquivo.py

No Windows, se o comando `python` não funcionar, use `py nome_do_arquivo.py`.
